# 데모

레이아웃을 올리고, 좁은 곳을 찾고, 관심 있는 패턴을 크게 살펴봅니다. 이 페이지에서는 분석 서버를 시작하지 않아도 저장된 결과를 바로 조작할 수 있습니다.

{% include live-demo-cta.html %}

**후보 위치와 주요 패턴이 먼저입니다.** 형상 검사는 살펴볼 위치를 찾고, 광학 화면은 주변 모양을 비교하도록 돕습니다. 초점·도즈 비교는 더 자세히 보고 싶을 때 선택하는 단계입니다.

## 1. 화면과 사용 가이드

라이브 분석 서비스에서는 새로운 공개 GDS/OAS 파일을 분석합니다. 아래 뷰어는 저장된 TT04 PWM 예시를 즉시 바꿔 보는 화면이며, 파일 업로드나 새 레이아웃 계산을 수행하지 않습니다.

| 항목 | 사용 방법 |
| --- | --- |
| File | Live Demo에서 공개 가능한 비기밀 레이아웃을 선택합니다. |
| Layer / Datatype | 검토할 형상을 지정합니다. 이 페이지의 저장 예시는 67/20과 68/20입니다. |
| Width / Space limit | 형상 후보를 찾는 기준이며 인쇄 CD 합격 기준과 다릅니다. |
| ROI / Pixel size | 주변 검토 영역과 영상 간격입니다. 화면 확대와 실제 계산 범위는 구분합니다. |
| 후보 카드 | Width/Space와 표시 개수를 선택한 뒤 카드를 누르면 큰 이미지가 바뀝니다. |
| 초점 / 상대 도즈 | 비교 기록이 있는 후보의 조건과 모델 측정값을 함께 살펴봅니다. |
| 기준 입력 | 라이브 앱의 안내를 따릅니다. 등록 예시 외 파일은 기준 위치·측정 방향·설계 폭이 필요할 수 있습니다. |
| 결과 해석 | 후보 위치와 모델 윤곽은 추가 검토를 돕는 정보이며 불량·제조 안전을 확정하지 않습니다. |

### 라이브 앱을 처음 사용할 때

등록된 공개 예제로 시작하고, 후보 위치를 확인한 뒤 주변 윤곽을 비교해 보세요. 앱에서 요청하는 경우 입력 파일의 의미 있는 설계 형상을 기준으로 사용자 기준 정보를 지정합니다. 예시의 기준은 설계 비교용이며 실측 웨이퍼에 맞춘 보정이 아닙니다.

저장 뷰어와 현재 라이브 앱의 배치는 다를 수 있습니다. 새 계산은 Live Demo에서, 결과 해석 학습은 아래 뷰어에서 진행하면 됩니다.

## 2. 후보 위치를 보고 선택하기

아래 지도는 TT04 PWM 67/20의 저장된 예시 위치입니다. W는 선폭, S는 간격 예시입니다. 표시는 살펴볼 위치를 뜻하며 확정된 불량이 아닙니다.

![공개 TT04 PWM 67/20에서 저장된 선폭·간격 예시 위치]({{ '/assets/demo/public/candidate-locations.png' | relative_url }})

67/20에는 유형별 6개, 68/20에는 유형별 1개 후보가 있습니다. 두 레이어 모두 Width·Space의 1번 후보에 초점·도즈 기록이 연결됩니다. 다른 카드는 기본 이미지를 제공하며 비교 기록이 없다는 사실을 명시합니다.

## 3. 실제 사례 비교

### TT04 PWM 67/20

67/20에서 Width 1과 Space 1을 비교해 보세요. 두 설계 치수는 170 nm이지만 정초점·기준 도즈의 모델 치수는 각각 약 166.34 nm와 199.44 nm입니다. 설계 형상과 모델 윤곽은 다른 양이며, 후보마다 설계 치수를 재현하도록 따로 맞춘 결과가 아닙니다.

6개 카드를 눌러 긴 좁은 선, 인접한 선 끝과 서로 다른 간격 모양을 비교할 수 있습니다. 카드를 선택하면 큰 이미지가 바뀝니다. 선택 비교를 펼치면 기록이 있는 후보의 특정 초점·도즈 조건을 살펴볼 수 있습니다.

### TT04 PWM 68/20

68/20의 Width 1은 목이 좁아지는 패턴입니다. 설계 폭은 140 nm이고 정초점·기준 도즈의 모델 폭은 약 87.88 nm입니다. 상대 도즈 0.90·초점 ±0.20 µm에서는 고정된 검토 위치의 형상을 모델에서 측정할 수 없습니다. 뷰어는 0으로 채우지 않고 ‘측정 불가’로 표시하며, Bossung 곡선도 그 구간을 연결하지 않습니다.

같은 예시 기준을 사용한 주변 영역의 반응입니다. 레이어 전체의 성능 순위나 실제 웨이퍼 불량 판정은 아닙니다.

## 4. 그림과 비교 결과 읽기

| 표시 | 의미 |
| --- | --- |
| 회색 형상 | 검토 위치 주변의 입력 마스크 모양. |
| 따뜻한 색의 빛 분포 | 모델의 aerial image이며 실측 레지스트 단면이 아님. |
| 십자 | 주변 검토 위치이며 좌표는 그 위치를 기준으로 표시. |
| 기본 윤곽 | 정초점에서 상대 도즈 0.90·1.00·1.10의 비교. |
| 비교 화면의 파란 윤곽 | 선택한 초점·도즈 조건. |
| 설계 치수와 모델 치수 | 설계 형상과 기록된 위치에서 측정한 윤곽의 차이. |
| Bossung 곡선 | 도즈별 초점 대 모델 치수이며 초점은 3점만 존재. |

9개 조건의 그림과 측정값 표도 펼칠 수 있습니다. 수치는 소수 둘째 자리로 표시하며, 그 표기 정밀도가 물리 정확도를 뜻하지는 않습니다. 측정 불가는 0으로 바꾸거나 보간해 연결하지 않습니다.

## 5. 조건과 해석의 한계

| 항목 | 저장된 예시의 조건 |
| --- | --- |
| 입력 | 공개 TT04 PWM, layer/datatype 67/20·68/20 |
| 광학 모델 | 스칼라·얇은 이진 마스크, 파장 248 nm, NA 0.68, conventional 조명 σ=0.60 |
| 초점 | −0.20·0.00·+0.20 µm |
| 상대 도즈 | 0.90·1.00·1.10, 무차원이며 mJ/cm²가 아님 |
| 주변 화면 | 1.28 × 1.28 µm 확대, 검토 위치 기준 x/y 좌표 |
| 비교 | 고정된 예시 위치와 하나의 설계 기준, 같은 후보의 초점별 강도 색 범위 유지 |

초점 3점은 경향 확인용이며 정밀한 DOF 추정이 아닙니다. CD 합격 기준을 적용하지 않습니다. Threshold 윤곽은 레지스트 화학·식각 모델이 아닙니다. 선택 예시가 전체 레이아웃 정확도·공정 창·호스팅 실행 시간을 보증하지 않습니다.
