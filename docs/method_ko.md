# 방법론

GeoSignal은 레이아웃 검토를 단순화된 광학 시각화와 연결합니다. 이 페이지는 사용자가 보는 개념을 설명하며, [기술 노트]({{ '/ko/notes/' | relative_url }})에서 표준 광학 원리를 더 자세히 다룹니다.

## 1. 개념적인 흐름

레이아웃 → 후보 영역 → 주변 광학 이미지 → 윤곽 비교 → 사용자 검토.

형상 검사는 살펴볼 위치를 찾습니다. 광학 화면은 주변 형상이 선택한 패턴에 어떤 영향을 줄 수 있는지 보여줍니다. 전체 레이아웃의 모든 지점을 시뮬레이션하는 흐름은 아닙니다.

## 2. 형상 화면과 광학 화면

형상 검토는 폭·간격·주변 모양을 살펴봅니다. 광학 이미지는 모델의 빛 강도이며, 윤곽은 선택 패턴을 다른 관점에서 보여줍니다. 두 화면을 함께 보면 설계 형상과 모델 영상의 차이를 이해하는 데 도움이 됩니다.

## 3. 초점과 상대 도즈

초점 변화는 간섭과 영상 대비를 바꿀 수 있습니다. 상대 도즈는 비교 기준에 대한 모델 노광량의 변화입니다. 초점·도즈 비교는 명시한 모델·허용 기준 안에서 해석해야 하며, threshold 윤곽이 정합된 레지스트 공정을 대신하지 않습니다.

## 4. 공개 예시 읽기

[데모]({{ '/ko/demo/' | relative_url }})에 예시의 파장·조명·단위·비교 조건을 정리했습니다. 같은 위치를 조건별로 비교하고, 하나의 폭이나 그림만으로 결론내리기보다 형상 변화를 먼저 살펴보세요.

공개 그림은 대표 예시이며 범용 정확도·속도 벤치마크가 아닙니다. 내부 구현·보정 절차·상세 엔지니어링 평가는 별도로 관리합니다.

## 5. 범위와 한계

이상화된 스칼라 광학과 얇은 이진 마스크를 사용합니다. 벡터·고 NA scanner 정합성, mask-3D 산란, 레지스트 화학, 식각이나 제조 승인을 검증하지 않습니다. 공개·합성 레이아웃 예시를 사용하며, 공개 데모에 기밀 입력을 업로드하면 안 됩니다.
