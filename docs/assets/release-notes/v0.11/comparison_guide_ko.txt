# GeoSignal 변수–Metric 비교 테이블 사용법

이 문서는 Canonical187,392행 비교 Snapshot의 해석 가이드다. 이후 보통1,344행과 [TT04 자원 검토](../render_feasibility/RENDER_FEASIBILITY_KO.md)가 별도 추가되었다. 아래 TT04 “Optical 미실행”은 이 비교표의 초기 Raster-only 열에 대한 설명이다. 신규 자원 표는 실제 Abbe 시간을 측정했지만 TT04 Optical Accuracy Reference를 추가한 것은 아니다.


목적: 기존 측정 결과를 조건별로 정리하고, 다른 조건을 고정한 변수 비교를 지원한다. 이번 작업은 신규 Optical 실험이나 최적점 확정이 아니다.

행의 의미: conditions.csv.gz의 한 행은 Pattern / Source / Mask Pixel / AI Pixel / Raster / Interpolation / Radius / Mask Phase / AI Phase 한 조건이다.
Split 정보: dataset은 shared_grid / split_cell51 / split_equal101, grid_relation은 공유 또는 독립 격자를 구분한다. condition_id는 Phase까지 포함한 고유 ID다.
Phase 좌표: mask_phase는 고정 Mask Grid에 대한 Geometry Translation이다. image_phase는 독립 AI Grid 원점의 추가 이동이다. shared_grid는 추가 AI Grid 이동이 없어 image_phase=0이며, Pattern Translation의 AI Sampling 효과는 mask_phase로 추적한다.
전체 조건: 공유 격자 165,888행에는 기존 Dense7/11 + Binary10nm + Bilinear가 포함된다. 독립 격자 21,504행을 더해 고유 정확도 조건은 187,392행이다. 원래 1,756행은 독립 A/B/C 실험과 SOCS 등 의미가 다른 Archive이며 단순 합산하지 않는다.
사례별 시트: LS125 / LS150 / LS250 / LS137 / LS100_unresolved / CONTACT180 / TT04PWM. TT04PWM은 Rasterization만 측정했다.
사례 요약: case_summary.csv에는 28,032개 수치 설정이 있다. Phase를 묶은 max / p95 / median CD Error, RMSE, Stage Error, Status, Joint Gate, 실측 Runtime을 기록한다. 동일 설정의 여러 Phase는 독립 반복 실험이 아니다.
통제된 비교: matched_pairs.csv.gz의 115,920쌍은 나머지 변수 및 Phase 집합을 고정한다. Source Density는 7, Weighting은 equal, Raster는 binary, Interpolation은 bilinear, 공유 Pixel은 10nm, 독립 AI Pixel은 25nm, Blackman Radius는 4를 비교 기준으로 삼는다.
변수 편차: variable_effects.csv는 통제된 비교에서 Metric 변화의 mean / median / p95 / min / max / std 및 개선·악화 쌍 수를 제공한다. 음의 Error Delta는 개선이다. 표준편차는 설정에 따른 효과 편차이며 측정 반복의 불확실성이나 신뢰구간이 아니다.
진단 조건: Bandlimited Oracle는 원본 조건표와 matched_pairs에 diagnostic_only로 보존한다. variable_effects의 실제 후보용 편차 요약에서는 Oracle가 포함된 비교 쌍을 제외한다.
가중치 해석: equal↔cell_area는 Boundary Cell 면적 및 대표 Node 처리, 실제 Point Count도 달라지는 비교다. 실제 측정된 장비 Source 분포를 적용한 결과나 Weight만 바꾼 효과로 해석하지 않는다.
상호작용 확인: matched_pairs의 baseline_summary_id / target_summary_id를 case_summary에 Join하면 Dense별 Raster 개선 효과, Pixel별 보간 개선 효과를 볼 수 있다. 다른 Stage Error를 가산·차감하여 원인 기여율로 해석하지 않는다.
Stage Reference: Source는 R1↔R0, Raster는 R2↔R1, Interpolation은 R3↔R2, Total은 R3↔R0 직접 비교다. Split 실험에서 저장되지 않은 Max Intensity Error나 보간 RMSE는 빈칸이다.
런타임: reduction_core_s는 Fourier 축약 계산 시간으로 실제 2D FFT/Render TAT가 아니다. production_timings.csv에 실측한 준비/FFT/Abbe/보간/측정 시간을 별도로 둔다. 조건 테이블의 실측 시간은 Physical Parameters, Grid, Method, Phase가 정확히 일치하는 295행에만 연결했다.
대표 런타임: case_summary의 representative_production_compute_s는 같은 설정의 측정된 대표 Phase 한 지점 시간이다. 모든 Phase의 최대·평균 시간으로 해석하지 않는다. representative_timing_id와 Runtime_measured 시트에서 측정 범위와 반복 횟수를 확인한다. 나머지는 NOT_MEASURED / 빈칸이며 추정하지 않았다.
통제된 시간 비율: matched_pairs의 production_compute_ratio는 실제 측정된 두 설정 중 같은 Mask/Image Phase의 시간만 사용한다. runtime_baseline_id / runtime_target_id로 원본을 추적하며, 시간 쌍이 없으면 빈칸이다.
메모리: production RSS는 worker high-water, TT04 RSS는 누적 process high-water다. 증분 메모리로 혼합 비교하지 않는다.
CD 결측: Reference가 VALID인 조건에서 Crossing을 측정할 수 있을 때만 Error가 있다. Crossing 실패를 CD Error=0으로 바꾸지 않는다. False Printing / Missing Crossing 및 conditional_pass_all을 함께 확인한다.
CD 비교 가능성: 통제된 CD 비교는 양쪽 조건에서 Reference의 모든 유효 Phase CD가 측정되고 False Positive가 없을 때만 한다. 유효하지 않은 쌍의 CD Delta는 빈칸으로 유지하며 RMSE와 Status 편차는 기록한다.
Contact 축 상태: 공유 격자에서는 저장된 X/Y 중 한 축이라도 Crossing이 실패한 비교를 CD Delta에서 제외한다. Split 원시 기록은 X 상태만 저장했으므로 axis_status_scope를 확인해야 하며, 저장되지 않은 Y 실패 건수를 추정하지 않는다.
Grid Phase: cd_error_phase_range_nm은 절대 CD Error의 범위다. printed_cd_x_phase_range_nm은 실제 Printed CD의 범위로 별도 열이다. Split 원시 결과에 실제 Printed CD가 저장되지 않아 해당 Printed CD Range는 빈칸이다.
Threshold: KrF 248nm / NA0.68 / sigma0.6, Focus0, Raw Threshold0.30, D0=1, 주기 경계 조건이다. 제품의 자동 Dose Calibration 결과와 동일하지 않다.
TT04PWM: 실제 Layout의 Mask 면적 및 Rasterization Runtime만 비교한다. AI RMSE / CD / Optical TAT는 NOT_EXECUTED다. 주기 L/S 계산 시간과 TT04 Raster 시간을 합쳐 실측 전체 서비스 TAT로 표기하지 않는다.
Archive: legacy_archive.csv.gz는 기존 결과를 보존하고 전수 조건과 겹치는 Configuration ID 및 과거 비정수 Pitch/Pixel 축약 한계를 표시한다. 수정된 Full Cross를 우선하며 Archive를 다시 독립 표본으로 합산하지 않는다.
범용성: LS100뿐 아니라 LS125도 이 고정 Threshold에서는 Reference Crossing이 형성되지 않는다. 이를 별도 사례로 유지한다. 한 Contact Size/Pitch와 제한된 주기 Pattern의 결과는 범용 최적점이나 실제 장비 Signoff가 아니다.
후속 최적화: 먼저 사례·Reference Status·Joint Gate·허용 CD/RMSE를 정한 뒤, 실측 Runtime이 있는 설정으로 Pareto를 평가한다. 신규 Runtime 측정이 필요한 설정은 후보로 표시한다. TT04 Optical 및 Focus/Dose 확장은 별도 실험이다.
재실행: .venv/bin/python -m src.benchmark.comparison_tables --root . --output work/comparison_tables
Excel 의존성: xlsxwriter==3.2.9 (CSV 생성은 --no-excel로 추가 패키지 없이 가능). Production 기본 설정이나 Optical 구현을 바꾸지 않는다.
