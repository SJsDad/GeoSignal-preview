# v0.3 릴리즈 노트

## 주요 내용

v0.3에서는 모듈형 geometry-analysis architecture를 구성했습니다.

주요 추가 사항은 다음과 같습니다.

* 공통 geometry operation
* edge-aware directional INTERNAL 및 EXTERNAL rule
* 공통 layout reader
* width/space binning 및 histogram 분석
* 선택 가능한 analysis box를 포함한 grid-based density 분석

## 과거 기록

이 마일스톤은 `ed410d4` 커밋까지의 이력을 바탕으로 복원했습니다. 별도 benchmark 및 validation artifact는 보존되지 않았습니다.
