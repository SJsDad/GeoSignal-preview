# v0.4 — 광학 반응 시각화

이 페이지는 해당 단계의 주요 변경과 적용 범위를 요약합니다.

## 주요 변경

* 선택한 검토 위치 주변의 광학 이미지와 윤곽을 추가했습니다.
* 형상 후보를 주변 패턴의 모양 비교와 연결했습니다.

## 검토 범위

초기 단계는 보존된 개발 기록을 바탕으로 요약했습니다. 별도의 정량 성능 자료가 부족하므로 이후 버전의 수치를 이 단계에 소급하지 않습니다.
