# v0.4 릴리즈 노트

## 주요 내용

v0.4에서는 geometry로 선택한 영역을 simplified lithography imaging 및 contour-review pipeline에 연결했습니다.

주요 추가 사항은 다음과 같습니다.

* clip 기반 layout rasterization
* imaging configuration 및 source sampling
* FFT frequency grid 및 shifted pupil 생성
* partial-coherent Abbe aerial imaging
* direct threshold contour 추출 및 multi-threshold 비교
* geometry 기반 hotspot candidate 및 구조화된 risk metric
* TinyTapeout width/space 평가 결과

## 과거 기록

이 마일스톤은 `92fea31` 커밋까지의 이력을 바탕으로 복원했습니다. 별도의 release-level benchmark artifact는 보존되지 않았습니다.

## 초기 Pages 이미지 모음

이 legacy 이미지 세트는 v0.4 구현을 보여 줍니다. 직접 주석을 표시한 Home 이미지와 dense11 ROI overlay 네 장을 초기 presentation의 과거 기록으로 보존합니다.

이 이미지들은 현재 Render-aligned interface나 pya-native 결과 형식을 나타내지 않습니다. 현재 Home과 Demo에는 별도로 정리한 v0.10 결과를 사용합니다.

## 평가 자료의 범위

이 버전은 남아 있는 소스 이력으로 구현 범위를 확인한 기록입니다. 별도의 실행 시간·메모리·수치 오차 원본이 보존되어 있지 않아 정량 성능 표나 그래프를 새로 만들지 않았습니다. 이후 버전의 수치를 이 버전의 결과로 소급하지 않습니다.

기존 gallery는 당시 시각화 산출물입니다. 원래 mask와 밝기 분포, 후보 위치, 고정 threshold contour를 비교해 모서리·선 끝의 변화를 보는 용도입니다. 실제 공정 보정 또는 현재 상대 도즈 모델의 증거는 아닙니다. 이미지에 표시된 조건만 해당 그림에 적용하며, 기록되지 않은 조건을 추정하지 않습니다.
