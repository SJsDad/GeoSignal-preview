# v0.4 Release Notes

## Main Focus

v0.4 connected geometry-selected regions to a simplified lithography imaging
and contour-review pipeline.

Key additions included:

* clip-based layout rasterization
* imaging configuration and source sampling
* FFT frequency grids and shifted pupil generation
* partial-coherent Abbe aerial imaging
* direct threshold contour extraction and multi-threshold comparison
* geometry-derived hotspot candidates and structured risk metrics
* TinyTapeout width/space evaluation outputs

## Historical Record

This milestone is reconstructed through commit `92fea31`.
Separate release-level benchmark artifacts were not preserved.
