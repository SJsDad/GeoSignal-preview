# v0.9 — 광학 계산 일관성 검토

이 페이지는 해당 단계의 주요 변경과 적용 범위를 요약합니다.

## 주요 변경

* 같은 예시 조건에서 광학 계산의 일관성을 비교했습니다.
* 정확한 수치 일치와 근사 모델의 한계를 구분해 검토했습니다.

## 검토 범위

공개·합성 예시에서 기능과 결과의 일관성을 검토했습니다. 이 기록은 모든 레이아웃의 정확도·실행 시간이나 실제 웨이퍼 공정 정합성을 보증하지 않습니다. 상세 구현·보정·성능 평가는 비공개 기술 기록으로 관리합니다.
