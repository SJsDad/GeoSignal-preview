# v0.9 릴리즈 노트

> GeoSignal v0.9.0은 현재 public preview입니다. Tag가 지정된 application
> revision은 [GitHub Release](https://github.com/SJsDad/GeoSignal-lab/releases/tag/v0.9.0)에서
> 확인할 수 있습니다.

## 주요 내용

v0.9는 exact Hopkins/TCC/SOCS 경로를 추가하고 v0.8.1 Abbe reference와
교차검증했습니다. 이 milestone의 목적은 numerical 및 architectural
equivalence입니다. Public service default를 변경하거나 approximate truncated
result를 암묵적으로 사용하지 않습니다.

## Exact TCC와 Full-Rank SOCS

다음 내용을 구현했습니다.

* Abbe와 동일한 source point, weight, shifted pupil, FFT ordering, defocus
  phase를 사용하는 guarded small-array discrete TCC reference
* deterministic Hermitian full-rank SOCS construction
* round-off negative eigenvalue 처리 및 phase-canonicalized mode
* production-size explicit TCC 대신 source-space Gram matrix를 사용하는 exact
  `HopkinsAerialImageBackend`
* backend-neutral process-window 및 CD measurement orchestration 보존

6개 deterministic mask, dense7/dense11, focus `-0.15`, `0.0`, `+0.15 µm`를
포함하는 12 x 12 golden matrix의 결과는 다음과 같습니다.

| 비교 | Maximum absolute aerial error |
| --- | ---: |
| Explicit TCC vs. Abbe | `3.66e-15` |
| Full-rank SOCS vs. Abbe | `6.55e-15` |

두 경로 모두 `rtol=1e-9`, `atol=1e-11` equivalence gate를 통과했습니다.
18-condition backend-neutral PW/CD 비교에서는 ordering, topology status, PASS
grid, common-PW count, sampled depth of focus가 동일했으며 maximum valid CD
difference는 `4.86e-16 µm`였습니다.

## Bounded Optical-Mode Cache

Exact Hopkins backend는 raster shape, 전체 immutable imaging configuration,
physical focus를 key로 사용하는 thread-safe LRU를 사용합니다. Default bound는
8개 entry와 retained NumPy mode payload `128 MiB`입니다. Hit, miss, eviction,
oversized skip, entry count, retained bytes를 진단 정보로 제공합니다.

Deterministic `320 x 320` dense7, `focus=+0.15 µm` 사례의 결과는 다음과
같습니다.

| 측정 | 결과 |
| --- | ---: |
| Warm Abbe median | `234.22 ms` |
| Hopkins first cache miss | `390.56 ms` |
| Hopkins cache-hit median | `115.10 ms` |
| Maximum aerial error | `2.66e-15` |
| Retained Hopkins mode payload | `45.31 MiB` |

이 사례에서 cached evaluation은 더 빨랐지만 first miss는 더 느리고 memory
사용량도 훨씬 컸습니다. 이 결과는 bounded reuse의 근거이며 service default를
변경할 근거는 아닙니다.

## Truncation 평가와 결정

Approximate SOCS truncation은 mode count, retained energy, aerial error, CD
error, runtime, payload 진단을 명시하는 별도 경로로 평가했습니다.

* `320 x 320` dense7 사례의 99% energy policy는 29개 중 25개 mode를
  유지했지만 maximum aerial error `9.82e-4`, PW-case CD error `2.22e-4 µm`를
  기록했습니다.
* 6개 mask, dense7/dense11, 3개 focus를 포함하는 36개 aerial case에서
  99.99% energy도 strict case 36개 중 21개만 통과했습니다.
* 100% retained energy만 36개 case를 모두 통과했으며 mode를 줄이지 못했습니다.
* Dense11 PW extension의 99.99% energy에서도 maximum CD error는
  `2.58e-5 µm`였습니다.

평가한 truncated policy 중 combined aerial 및 `1e-6 µm` CD gate를 만족한
정책은 없습니다. 따라서 truncation policy를 safe default로 선택하지
않았습니다. Abbe는 service default, full-rank Hopkins는 exact alternative,
truncated SOCS는 명시적으로 구분한 evaluation path로 유지합니다.

## 검증 요약

Golden aerial equivalence, cache-key separation, LRU eviction, byte-budget
bypass, backend-neutral PW/CD reuse를 포함한 자동화 test 69개를 모두
통과했습니다.


## 보존된 평가 자료 상세

아래 그래프는 당시 보고서에 남은 수치를 다시 시각화한 것입니다. 새 실행이나 현재 버전의 benchmark가 아닙니다. CSV는 보존된 표의 전사본이며 원시 반복 측정 trace는 아닙니다.

### 조건과 해석

정확한 backend의 작은 golden matrix는 12 × 12 배열의 여섯 deterministic mask, dense7/dense11, focus −.15/0/+.15 um입니다. Explicit TCC/Abbe와 full-rank SOCS/Abbe의 최대 absolute aerial error는 각각 3.66e-15 / 6.55e-15로 round-off 수준입니다. 동일 source·weight·pupil·FFT convention을 비교한 알고리즘 동등성이지 실측 공정 정확도 검증이 아닙니다.

Cache 표의 320 × 320 dense7, focus +.15 um에서 첫 miss 390.56 ms는 warm Abbe 234.22 ms보다 느리고 hit median 115.10 ms는 빠릅니다. Cache mode payload 45.31 MiB를 사용하므로 무조건적인 성능 우위가 아닙니다. Retained cache는 8 entries / 128 MiB로 제한했습니다.

Truncation의 320 배열 시간은 warm image 계산 5회 median입니다. 99.9% 정책이 29/29 mode를 선택한 경우 실제 truncation이 아닙니다. Logical selected-mode bytes는 계산 payload이며 backend는 full-rank mode를 cache하므로 실제 cache 메모리 절감으로 읽으면 안 됩니다.

36-case 비교는 32 × 32, 여섯 mask, dense7/dense11, focus −.25/0/+.25 um입니다. Strict gate는 rtol=1e-9, atol=1e-11입니다. 일부 dark/degenerate case의 통과는 강한 mode 축소의 일반적 동등성 근거가 아닙니다. 100%만 36개 모두 통과했고 이때 mode 축소는 없었습니다.

PW 표는 두 후보 × 세 focus × 세 dose = 18측정의 전체 workflow 시간입니다. Common-PW count가 0인 사례이므로 같은 PASS/DoF만으로 동등성을 주장할 수 없습니다. Dense11 99.99%에서도 CD error 2.577e-5 um로 1e-6 um gate를 넘습니다. 따라서 Abbe default와 exact full-rank 대안은 유지하고 approximate truncation은 평가 경로로 남겼습니다.
