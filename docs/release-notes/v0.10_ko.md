# v0.10 — 검증 snapshot

이 v0.10 검증 snapshot은 모델과 preset을 설명합니다. 기재한 benchmark는 로컬 측정이며 실제 서버 성능은 다를 수 있습니다.

- Candidate: measured CD → area → deterministic tie-breaker. 누락된 CD는 후순위.
- Fixed design reference와 고정 단면 CD, 0.1 nm 이하 fitting 허용 오차. 실패 시 임의 threshold 대체 없음.
- Raw intensity에서 `T_eff=T0/(D0*d)` 사용. T0/D0는 독립 실측 물성이 아니며 mJ/cm² 단위도 아님.
- Speed dense7 / Internal dense11. Pixel 10 nm, ROI 2.56 µm, ambit 0.32 µm 유지.
- 내부 DBU 0.1 nm 통일, hierarchy와 물리 크기 보존, export 재읽기 확인.
- Hole 및 domain 경계를 보존하는 pya Region과 Euclidean width/space screening. Anchor CD와 별도 지표.
- Pixel 중심이 경계와 일치하는 경우의 포함 규칙을 안정화. 이 수정 전의 Tnorm은 재사용하지 않음.
- 공개 페이지의 개발 날짜·일정 제거. 기존 고정-threshold 이미지는 Legacy Demo로 격리.
