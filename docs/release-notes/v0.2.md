# v0.2 Release Notes

## Main Focus

v0.2 moved the early geometry experiment into an initial Flask web prototype.

The milestone added browser-based layout upload and preview behavior, separated
the service flow from the presentation layer, and established the first public
shape of the GeoSignal demo.

## Historical Record

This milestone corresponds to commit `d370f7c` and the existing
legacy Git tag `v0.2`. Separate benchmark artifacts were not preserved.
