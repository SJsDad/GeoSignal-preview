# v0.10 — validation snapshot

This is a locally validated v0.10 snapshot. The live Render deployment may differ.

- Candidate priority: measured CD, area, deterministic ties; missing CD last.
- Separate design reference and fixed-gauge CD, with a 0.1 nm fitting tolerance and explicit failure.
- Raw intensity and `T_eff=T0/(D0*d)`; T0/D0 are not independently measured material properties or mJ/cm².
- Speed dense7 / Internal dense11; pixel 10 nm, ROI 2.56 µm, ambit 0.32 µm.
- Internal 0.1 nm DBU with hierarchy/physical-size preservation and export roundtrip checks.
- Hole/domain-aware pya Regions and Euclidean width/space screening, separate from anchor CD.
- Stable inclusion of pixel centers on geometry boundaries. Earlier Tnorm values are not reused.
- Public development chronology removed; old fixed-threshold images isolated in Legacy Demo.
