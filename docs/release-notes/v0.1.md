# v0.1 Release Notes

## Main Focus

v0.1 established the initial GeoSignal project structure and a local,
CLI-oriented geometry-rule workflow.

The early implementation explored SVRF-like minimum-width and minimum-space
checks, along with small debug layouts and console-based inspection. It was a
development prototype rather than a public web demo.

## Historical Record

This milestone is reconstructed from repository history through commit
`b9db447` on 2026-02-16. Separate benchmark and validation artifacts were not
preserved for this version.
