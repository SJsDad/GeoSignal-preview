# v0.12 — 6f 광선·파동 시뮬레이터

v0.12는 학습용 **6f 광선 추적·푸리에 광학 시뮬레이터**를 GitHub Pages에 추가합니다. 한글·영문 화면을 따로 제공하고, 기술 노트·논문 리뷰·탐색 메뉴도 대응하는 언어로 연결합니다.

[한글 시뮬레이터 실행]({{ '/ko/simulator/' | relative_url }}) · [광학 원리 읽기]({{ '/ko/notes/diffraction-defocus/' | relative_url }})

## 1. 광선도를 중심으로 같은 회절항의 파동 연결

기본 화면은 Source 0f → Condenser 1f → Mask 2f → Objective 3f → Pupil 4f → Imaging lens 5f → Wafer 6f를 따라갑니다. 동일 초점거리의 얇은 렌즈가 조명을 평행광으로 만들고, 각 회절 차수를 pupil의 한 위치로 모읍니다. 차단된 광선은 pupil에서 멈추며 통과한 차수는 도립상으로 이어집니다.

기본은 0·±1차입니다. Pupil 진폭·위상, 복소 전계와 웨이퍼 강도는 같은 선택 차수·통과 조건을 사용합니다. 수직 3-beam, 대칭 2-beam, 고차 회절 프리셋을 비교할 수 있습니다. 확장 설정에는 듀티 비, 최대 ±32차, 파장·피치, 근축 또는 스칼라 angular-spectrum 위상이 있습니다.

## 2. Pages에서 직접 실행

HTML·JavaScript·Canvas가 브라우저에서 계산하며 Render API를 호출하지 않습니다. 선택적으로 펼치는 through-focus 맵은 별도 Worker가 계산합니다. 따라서 시뮬레이터의 Render 서버 기동 대기가 사라지며, 최초 페이지·파일 다운로드 시간은 네트워크와 브라우저에 따라 달라집니다.

GDS/OAS 업로드와 레이아웃 분석은 Python·Render 서비스를 계속 사용합니다. 시뮬레이터의 Python 기준 엔진·API는 수치 비교용으로 유지합니다. 이번 버전은 v0.11의 샘플링 후보를 레이아웃 분석 화면에 도입하는 변경이 아닙니다.

## 4. 문서 대칭화

영문 Abbe·Fourier optics·회절/디포커스 노트에 한글판의 유도와 예제를 채웠습니다. Hopkins/TCC/SOCS, inverse/metrics, 논문 리뷰 8편, 개요·적용 범위·출처 기록에도 영문 대응 페이지를 추가했습니다. 두 언어는 같은 55개 Figure 출처 기록과 같은 접근·검증 제한을 유지합니다.

공통 언어 전환 링크, 언어별 데모 버튼·목록·문서 경로·논문 이전/다음 링크가 대응 언어로 연결됩니다. 릴리즈 목록과 홈에서도 이번 버전을 안내합니다.

## 5. 검증과 유지 관리

Python·브라우저 수치 비교, 얇은 렌즈 광선 행렬, 한영 시뮬레이터, 설정을 유지하는 언어 전환, 프리셋·pupil 차단·선택적 Worker 맵·모바일 배치·Render 요청 없는 정적 실행을 검증합니다. Jekyll 검사에는 대응 언어 경로, 생성된 링크·파일과 Figure 출처 일치 여부가 포함됩니다.

애플리케이션 저장소가 공통 템플릿·기본값·브라우저 파일에서 두 Pages 화면을 생성합니다. Export 검사로 복사본의 오래된 상태를 찾고, 공개 manifest에 파일 해시를 남깁니다. 언어마다 물리 구현을 따로 만들지 않고 같은 수학 엔진을 사용합니다.

## 6. 모델의 한계

이상화된 얇은 주기적 1D 마스크, 단일 결맞음 광원점과 균일한 공기 매질을 가정합니다. 광선도는 근축 모델입니다. Angular-spectrum 위상도 스칼라 옵션으로, 벡터·고 NA scanner·mask-3D 검증을 대신하지 않습니다. 광선도의 초점면 이동만 ×2000으로 확대 표시하며 파동 계산에는 실제 µm를 사용합니다.

대칭 2-beam의 초점 불변성은 이상적인 간섭 결과이며 공정 DOF가 무한하다는 뜻이 아닙니다. Through-focus 강도 맵은 CD/Bossung 곡선이 아닙니다. 유한 광원, 레지스트 화학, 제조 규칙과 웨이퍼 정합성은 별도 모델·검증이 필요합니다.
