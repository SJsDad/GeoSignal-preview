# v0.12 — 6f 광선·파동 시뮬레이터

v0.12는 한영 교육용 시뮬레이터를 GitHub Pages에 추가하고, 학습 노트의 언어별 구성을 맞춥니다.

## 주요 변경

* 광원부터 웨이퍼까지 6f 광선을 따라가며 pupil 차단과 도립상을 확인합니다.
* 같은 선택 차수의 pupil 진폭·위상, 웨이퍼 강도, 고차 회절과 디포커스를 조작합니다.
* 현재 시뮬레이터 설정을 유지하며 한글·영문을 전환합니다.
* Render 레이아웃 분석 서비스의 기동을 기다리지 않고 브라우저에서 실행합니다.
* 저장된 레이아웃 결과의 후보 선택·확대·초점/도즈 비교를 제공하고, 홈·방법론의 충분한 설명을 유지합니다.

[한글 시뮬레이터]({{ '/ko/simulator/' | relative_url }}) · [English simulator]({{ '/simulator/' | relative_url }}) · [광학 원리]({{ '/ko/notes/diffraction-defocus/' | relative_url }})

## 공개 문서 범위

Pages에는 기능 소개·대표 결과·광학 기초·논문 해설·모델 한계·변경 요약을 남깁니다. 레이아웃 엔진의 내부 구현, 보정·튜닝 절차와 상세 벤치마크 자료는 비공개로 관리합니다. 6f 데모는 구현을 살펴볼 수 있는 공개 교육용 예제로 유지합니다.

## 검증과 한계

언어 연결·수식 렌더링·모바일 화면·프리셋·pupil 차단·초점 맵 조작을 확인합니다. 이상적인 얇은 주기적 마스크와 공기 중 스칼라 전파를 가정합니다. 이상적인 2-beam 초점 불변성은 공정 DOF가 무한하다는 뜻이 아니며, through-focus 강도 맵은 Bossung 곡선이 아닙니다.
