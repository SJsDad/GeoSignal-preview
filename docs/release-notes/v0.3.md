# v0.3 Release Notes

## Main Focus

v0.3 established the modular geometry-analysis architecture.

Key additions included:

* shared geometry operations
* edge-aware directional INTERNAL and EXTERNAL rules
* a common layout reader
* width and space binning and histogram analysis
* grid-based density analysis with an optional analysis box

## Historical Record

This milestone is reconstructed through commit `ed410d4` on 2026-03-18.
Separate benchmark and validation artifacts were not preserved.
