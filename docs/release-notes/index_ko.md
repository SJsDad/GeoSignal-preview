# 릴리즈 노트

사용자에게 달라진 기능과 검토 범위를 버전별로 요약합니다. 상세 구현·보정·튜닝·벤치마크 기록은 비공개 기술 문서로 관리합니다.

## 버전

최신 v0.12는 한영 6f 교육용 데모와 학습 노트를 제공합니다. v0.11은 수치 연구이며 현재 레이아웃 데모에 새 옵션을 추가한 것은 아닙니다.
