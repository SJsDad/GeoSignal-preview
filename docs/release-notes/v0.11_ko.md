# v0.11 — 수치 정확도 검토

v0.11은 단순화된 스칼라 광학 모델의 수치 연구입니다. 선택한 예시에서 수치적인 선택이 결과의 신뢰성과 비용에 어떤 영향을 주는지 검토했습니다. 라이브 레이아웃 분석 화면에 새 샘플링 옵션을 추가하는 변경은 아닙니다.

## 주요 관찰

| 주제 | 공개 요약 |
| --- | --- |
| 조명 샘플링 | 수치 밀도를 높이는 것만으로 결과가 단조롭게 좋아지지는 않습니다. |
| 형상 샘플링 | 격자의 위치와 형상 표현이 모델 모서리에 영향을 줄 수 있습니다. |
| 영상 보간 | 영상의 유사도와 윤곽 정확도를 구분해 평가해야 합니다. |
| 계산 비용 | 같은 작업 범위를 비교하고 준비와 반복 계산의 비용을 구분해야 합니다. |

## 근거와 한계

합성 패턴과 공개 레이아웃 예시를 사용한 연구입니다. 결과는 명시한 스칼라 모델에 속하며 실제 scanner·레지스트 정합성을 뜻하지 않습니다. 범용 최적 설정·정확도 보증·호스팅 서비스의 속도 향상을 주장하지 않습니다.

상세 설정·통제 비교·엔지니어링 측정·재현 절차는 비공개로 관리합니다. 공개 요약에는 연구의 목적과 한계를 남기고 구현 기록은 배포하지 않습니다.
