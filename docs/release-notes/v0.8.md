# v0.8 Release Notes

> Legacy single-condition peak-normalized previews are visualization only. Quantitative preview and PW share the raw-intensity, fixed-T0 dose-to-size convention; T_eff changes inversely with relative dose d.

## Main Focus

v0.8 extends the fixed-ROI optical review from a single normalized condition
to a physical focus/dose process-window workflow. The existing fast preview
remains available, while an optional sweep evaluates one fixed candidate over
bounded focus and relative-dose grids.

## Focus and Dose Model

The scalar, aberration-free Abbe pupil now accepts wafer-side `focus_um` and
propagates the corresponding defocus phase. Dose remains a resist-side
threshold operation:

```text
T_eff = T0 / (D0 * d)
```

The raw aerial image is therefore not rescaled for each dose. The process-window
path uses clear-field-relative intensity, while the legacy single-condition
preview used display-oriented peak normalization; it is not a quantitative dose result. This separation avoids
mixing a visualization convention with physical sweep measurements.

## Process-Window Analysis

The optional workflow adds:

* fixed-candidate focus/dose sweeps
* dose-to-size calibration at best focus
* explicit no-contour and topology-failure states
* sampled depth-of-focus and exposure-latitude summaries
* common process-window counts
* Bossung and process-window plots
* CSV and JSON result artifacts
* bounded UI controls for focus, dose, and candidate condition counts

Mask FFT and source-independent context are reused across focus conditions.
The process-window path defaults to `dense11` source quadrature; the fast
single-condition preview remains on `dense7`.

## Validation

The implementation added checks for focus-sign symmetry, through-focus
clear-field conservation, inverse-dose threshold behavior, topology failures,
common-PW summaries, and service integration. All 47 automated tests passed at
the v0.8 implementation milestone.

## Interpretation Limits

The sweep is a sampled, simplified-model process-window analysis. It is not a
scanner-calibrated resist or wafer prediction. A PASS cell describes the
configured contour/CD criteria on the sampled grid only.


## Detailed preserved evaluation evidence

The charts below replot values preserved in the historical reports. They are not new executions or current-version benchmarks. CSV downloads transcribe the preserved tables; they are not raw repeated-run traces.

### Conditions and interpretation

The baseline uses deterministic three-line synthetic GDS, pya-native, conventional sigma .60 and dense11 with 81 source points on local Windows / Python 3.12. Rows change raster and sweep sizes; they are not alternative algorithms solving an identical workload. Wall times are single unprofiled runs; inclusive phase timings overlap and must not be summed.

Repeated contour/CD measurement dominates dense dose sweeps at small rasters, while source/FFT computation dominates at 320 × 320. The default-grid proxy is not the production-raster full default. The historical full-default estimate of roughly 61 seconds or more, based on 91 aerial calls and 1,821 CD calls, is an extrapolation, not hosted latency.

Optimization gates retain dose-to-size, status/PASS grids, common-PW, sampled DoF and CD signatures. Current v0.10 reference results are documented separately. Original v0.8 Bossung/PW artifacts are not preserved in this checkout; current plots are not relabelled as v0.8 evidence.
