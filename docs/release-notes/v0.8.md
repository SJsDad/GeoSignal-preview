# v0.8 — Focus and relative-dose comparisons

This page summarizes the main changes and scope of this milestone.

## Main changes

* Added comparisons across focus and relative-dose conditions.
* Included modeled contour-width and acceptance-region views for selected examples.

## Review scope

Functionality and result consistency were reviewed on selected public/synthetic examples. This does not guarantee accuracy or runtime for every layout, or establish wafer-process fidelity. Detailed implementation, calibration and performance records are maintained privately.
