# v0.12 — 6f Ray and Wave Simulator

v0.12 adds a bilingual educational simulator directly to GitHub Pages and aligns the learning notes across languages.

## Main changes

* Follow the 6f rays from source to wafer, including pupil blocking and image inversion.
* Explore pupil amplitudes/phases, wafer intensity, higher orders and defocus with the same selected orders.
* Switch between English and Korean while retaining current simulator settings.
* Run the simulator in the browser without waiting for the Render layout-analysis service to start.
* Explore saved layout results through candidate selection, enlarged images and focus/dose comparisons; fuller Home and Method guidance is retained.

[English simulator]({{ '/simulator/' | relative_url }}) · [Korean simulator]({{ '/ko/simulator/' | relative_url }}) · [Optical principles]({{ '/notes/diffraction-defocus/' | relative_url }})

## Public documentation

Pages retains feature descriptions, representative results, optical foundations, research-paper explanations, limitations and change summaries. Layout-engine implementation, calibration/tuning procedures and detailed benchmark artifacts are maintained privately. The 6f demo remains an openly inspectable educational implementation.

## Validation and limits

Checks cover language links, math rendering, mobile layouts, presets, pupil blocking and focus-map interaction. The model assumes an ideal thin periodic mask and scalar propagation in air. Ideal two-beam focus invariance is not infinite process DOF; a through-focus intensity map is not a Bossung curve.
