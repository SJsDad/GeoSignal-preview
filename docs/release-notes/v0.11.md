# v0.11 — Numerical Accuracy Review

v0.11 is a numerical study of a simplified scalar optical model. It examines how numerical choices affect the reliability and cost of selected examples. It did not introduce new sampling options into the live layout-analysis interface.

## Main findings

| Topic | Public takeaway |
| --- | --- |
| Illumination sampling | Changing numerical density alone does not guarantee monotonic improvement. |
| Geometry sampling | Grid placement and shape representation can affect modeled edges. |
| Image interpolation | Image similarity and contour accuracy should be evaluated separately. |
| Computation cost | Compare equivalent workloads; setup and repeated evaluation have different costs. |

## Evidence and limits

The study uses synthetic patterns and public-layout examples. Results belong to the stated scalar model, not calibrated scanner/resist behavior. No universal best configuration, accuracy guarantee or hosted-service speedup is claimed here.

Detailed settings, controlled comparisons, engineering measurements and reproduction procedures are maintained privately. This public summary preserves the study's purpose and limits without distributing its implementation records.
