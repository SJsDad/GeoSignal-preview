# v0.8 릴리즈 노트

## 주요 내용

v0.8은 고정 ROI의 단일 normalized condition 검토를 physical focus/dose
process-window workflow로 확장했습니다. 기존 fast preview는 그대로 유지하며,
optional sweep는 하나의 고정 candidate를 제한된 focus 및 relative-dose grid에서
평가합니다.

## Focus와 Dose 모델

Scalar, aberration-free Abbe pupil에 wafer-side `focus_um`을 전달하고 해당
defocus phase를 반영합니다. Dose는 resist-side threshold 연산으로 유지합니다.

```text
effective threshold = nominal threshold / relative dose
```

따라서 dose마다 raw aerial image를 rescale하지 않습니다. Process-window 경로는
clear-field-relative intensity를 사용하고, legacy single-condition preview는 표시
목적의 peak normalization을 유지합니다. 이를 통해 visualization convention과
physical sweep measurement가 섞이지 않도록 했습니다.

## Process-Window 분석

Optional workflow에 다음 기능을 추가했습니다.

* 고정 candidate focus/dose sweep
* best focus에서의 dose-to-size calibration
* 명시적인 no-contour 및 topology-failure state
* sampled depth-of-focus와 exposure-latitude summary
* common process-window count
* Bossung 및 process-window plot
* CSV 및 JSON result artifact
* focus, dose, candidate condition count를 제한하는 UI control

Focus condition 사이에서 mask FFT와 source-independent context를 재사용합니다.
Process-window 경로는 `dense11` source quadrature가 default이고, 빠른
single-condition preview는 `dense7`을 유지합니다.

## 검증

Focus-sign symmetry, through-focus clear-field conservation, inverse-dose
threshold behavior, topology failure, common-PW summary, service integration을
검증했습니다. v0.8 구현 milestone에서 자동화 test 47개를 모두 통과했습니다.

## 해석 범위

이 sweep는 simplified model을 사용하는 sampled process-window 분석입니다.
Scanner-calibrated resist 또는 wafer prediction이 아닙니다. PASS cell은 설정된
contour/CD 기준을 sampled grid에서 만족한다는 의미로만 해석해야 합니다.
