# v0.2 릴리즈 노트

## 주요 내용

v0.2에서는 초기 geometry 실험을 Flask web prototype으로 옮겼습니다.

브라우저 기반 layout upload와 preview 동작을 추가하고, service flow를 presentation layer와 분리했으며, GeoSignal demo의 첫 공개 형태를 만들었습니다.

## 과거 기록

이 마일스톤은 2026-03-07의 `d370f7c` 커밋과 기존 legacy Git tag `v0.2`에 해당합니다. 별도 benchmark artifact는 보존되지 않았습니다.
