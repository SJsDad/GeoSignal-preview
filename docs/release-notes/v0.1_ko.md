# v0.1 릴리즈 노트

## 주요 내용

v0.1에서는 초기 GeoSignal 프로젝트 구조와 로컬 CLI 중심의 geometry-rule workflow를 구성했습니다.

초기 구현에서는 SVRF-like minimum-width 및 minimum-space check를 실험하고, 작은 debug layout과 console 기반 확인 방식을 사용했습니다. 공개 web demo가 아닌 개발 prototype 단계였습니다.

## 과거 기록

이 마일스톤은 `b9db447` 커밋까지의 저장소 이력을 바탕으로 복원했습니다. 이 버전의 별도 benchmark 및 validation artifact는 보존되지 않았습니다.

## 평가 자료의 범위

이 버전은 남아 있는 소스 이력으로 구현 범위를 확인한 기록입니다. 별도의 실행 시간·메모리·수치 오차 원본이 보존되어 있지 않아 정량 성능 표나 그래프를 새로 만들지 않았습니다. 이후 버전의 수치를 이 버전의 결과로 소급하지 않습니다.
