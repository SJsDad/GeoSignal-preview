# GeoSignal 적용 범위와 연구 연결점

공개 프리뷰에서 확인할 수 있는 기능과 논문 리뷰에서 다루는 연구를 구분합니다.

* 목차
{:toc}

## 공개 기능

| 영역 | 방문자가 살펴볼 내용 |
| --- | --- |
| 레이아웃 검토 | 공개·합성 예시에서 폭과 간격이 좁은 후보 위치. |
| 광학 화면 | 주변 빛 분포와 모델 윤곽. |
| 조건 비교 | 이상화된 모델 안에서 선택한 초점·상대 도즈의 변화. |
| 학습 | 독립적인 6f 광선·파동 데모, 광학 기초와 논문 리뷰. |

공개 범위는 교육용 검토 흐름입니다. 자동 OPC, 정합된 레지스트 화학, mask-3D 예측이나 제조 승인을 검증한 것은 아닙니다.

## 논문 리뷰의 해석

리뷰는 학습 광학 모델·조명 조건화·마스크 생성·형상 기반 보정 연구를 다룹니다. 관련 연구 방향을 설명하며, 논문을 검토했다는 이유로 해당 모델이 GeoSignal에 구현됐다고 볼 수는 없습니다.

## 모델의 한계

대표 그림이 전체 레이아웃의 오차를 보증하지 않습니다. Threshold 윤곽은 실측 레지스트 단면과 다르며, 이상적인 초점·도즈 비교는 정합된 웨이퍼 공정 창과 다릅니다. 공개 예시와 해석 조건은 [데모]({{ '/ko/demo/' | relative_url }})에서 확인할 수 있습니다.

## 공개 문서 범위

기능 소개·대표 결과·기본 원리·논문 해설·한계·변경 요약을 공개합니다. 내부 구조, 보정·튜닝 절차, 최적화 세부와 상세 벤치마크·재현 기록은 비공개로 관리합니다.
